GITHUB'GA JOYLASH (Shoxista uchun qisqa yo'riqnoma)

1. github.com saytida o'z gmailingiz bilan ro'yxatdan o'ting (Sign up).
2. "New repository" -> nomi: student-management-system -> Public -> Create repository.
3. "uploading an existing file" havolasini bosing va shu papkadagi hamma
   fayllarni (index.html, README.md, LICENSE, .gitignore, docs papkasi) sudrab tashlang.
   Pastda "Commit changes" ni bosing.
4. Settings -> Pages -> Branch: main, / (root) -> Save.
   1-2 daqiqadan so'ng sayt shu manzilda ochiladi:
   https://<github-login>.github.io/student-management-system/
5. Repozitoriya havolasini va sayt havolasini Word hisobotning oxiriga
   va o'qituvchining Excel jadvaliga yozing. GitHub sahifalaridan 2-3 ta
   skrinshot olib hisobotga qo'shing.
